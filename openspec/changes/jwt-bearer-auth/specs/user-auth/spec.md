## MODIFIED Requirements

### Requirement: 用户自助注册

系统 MUST 允许访客通过用户名、密码、角色（教师/学生）和已有班级完成自助注册。用户名 MUST 全局唯一；注册者只能选择系统中已存在的班级，不能自行创建班级。注册接口 MUST 为无需认证的 JSON 接口：成功时返回 2xx 成功响应但 MUST NOT 签发访问令牌（注册后仍需显式登录），校验失败时返回 4xx 与明确的 JSON 校验错误。

#### Scenario: 注册成功

- **WHEN** 访客提交未被占用的用户名、符合长度要求的密码、有效角色（教师或学生）和一个已存在的班级
- **THEN** 系统创建用户记录、关联所选班级（角色与班级以提交中的合法选择为准并由服务端校验），返回 2xx 成功响应，且响应中不包含访问令牌

#### Scenario: 用户名已被占用

- **WHEN** 访客使用数据库中已存在的用户名提交注册
- **THEN** 系统以 4xx JSON 拒绝创建并返回明确的校验错误，且不泄露该账号的角色或班级等其他信息

#### Scenario: 选择不存在的班级

- **WHEN** 注册请求中包含系统中不存在的班级标识
- **THEN** 系统拒绝注册并返回校验错误，不创建任何用户

#### Scenario: 密码不满足长度要求

- **WHEN** 访客提交的密码短于系统规定的最小长度
- **THEN** 系统拒绝注册并提示密码长度要求，不写入用户记录

### Requirement: 密码必须加盐哈希存储

系统 MUST NOT 以明文形式存储密码。持久化到数据库的 MUST 是带随机盐的哈希值；明文密码 MUST NOT 出现在数据库、应用日志、错误信息或任何接口响应中；相同密码的两个用户 MUST 得到不同的哈希值。

#### Scenario: 数据库中不存明文

- **WHEN** 任意用户完成注册后直接检查数据库中的用户记录
- **THEN** 密码字段为加盐哈希字符串（含算法标识与盐），不包含明文密码，且无法从该字段直接还原明文

#### Scenario: 相同密码产生不同哈希

- **WHEN** 两个用户使用完全相同的明文密码注册
- **THEN** 两人在数据库中的密码哈希值不同（各自使用独立随机盐），且两人后续都能各自登录成功

#### Scenario: 登录按哈希校验

- **WHEN** 用户提交密码登录
- **THEN** 系统使用哈希校验函数将提交密码与库中加盐哈希比对，而不是与任何明文比较；校验通过后才签发访问令牌

### Requirement: 账号密码登录

系统 MUST 提供账号密码登录 JSON 接口：凭据校验通过后签发一个 JWT 访问令牌并在响应体中返回（同时返回令牌类型与有效期信息）；系统 MUST NOT 通过 Set-Cookie 写入任何会话 Cookie，MUST NOT 在服务端保存会话状态。凭据错误时拒绝登录并返回 401。

#### Scenario: 使用正确凭据登录

- **WHEN** 已注册用户向登录接口提交正确的用户名与密码
- **THEN** 系统返回 200 JSON，响应体包含访问令牌、令牌类型（Bearer）与过期时间信息，且响应不设置任何会话 Cookie；客户端此后以 `Authorization: Bearer <令牌>` 访问受保护接口

#### Scenario: 使用错误凭据登录

- **WHEN** 用户提交不存在的用户名或错误的密码
- **THEN** 系统返回 401 与统一的"用户名或密码错误"提示，不区分"用户不存在"与"密码错误"，且响应中不包含令牌、不写入 Cookie

### Requirement: 登出

系统认证无状态：登出 MUST 由客户端完成——删除本地保存的访问令牌并回到登录页。系统 MUST NOT 依赖服务端会话失效来实现登出，也不要求存在服务端登出状态。

#### Scenario: 用户登出

- **WHEN** 已登录用户在前端发起登出
- **THEN** 本地保存的访问令牌被删除且页面回到登录页；此后客户端发出的请求不再携带 Authorization 头，调用受保护接口得到 401

#### Scenario: 登出不依赖服务端状态变更

- **WHEN** 用户登出
- **THEN** 不需要也不存在"清除服务端会话"的操作；登出效果对当前客户端立即生效，系统不为登出维护任何状态记录

### Requirement: 受保护接口的未认证访问拒绝

系统 MUST 对所有需要登录的服务端接口在服务端校验 `Authorization: Bearer` 中的 JWT，不得依赖前端路由、按钮隐藏或客户端本地令牌判断作为保护手段；令牌缺失、格式错误、过期或验签失败时 MUST 返回 401 JSON，且不执行该接口的任何业务逻辑、不返回任何业务数据。

#### Scenario: 未登录调用受保护接口

- **WHEN** 请求未携带 Authorization 头却调用受保护接口（如材料列表、上传、下载接口）
- **THEN** 系统返回 401 未授权 JSON，不执行业务逻辑、不返回任何业务数据

#### Scenario: 令牌过期或验签失败

- **WHEN** 请求携带已过有效期、签名被篡改或声明缺失的令牌调用受保护接口
- **THEN** 系统返回 401，不返回任何业务数据，前端据此引导用户重新登录

#### Scenario: 服务端保护不依赖前端隐藏

- **WHEN** 使用 curl、脚本等工具在不登录、不运行前端页面的情况下直接调用受保护接口
- **THEN** 系统独立完成令牌校验并返回 401，是否存在前端入口或按钮不影响判定

## ADDED Requirements

### Requirement: 公开页面外壳与受保护数据接口隔离

承载前端的 HTML/JS/CSS 外壳页面 MUST 可以在无令牌时公开访问，但其服务端响应 MUST NOT 包含任何业务数据（材料内容、材料元数据或班级私有信息）；全部业务数据只能通过携带有效 Bearer 令牌的 `/api` 数据接口获得。前端在数据接口返回 401（含令牌过期）时 MUST 清除本地令牌并引导用户回到登录页。

#### Scenario: 未登录打开外壳页面

- **WHEN** 未登录用户在浏览器打开应用入口（登录页或应用外壳地址）
- **THEN** 系统返回可加载的静态 HTML 外壳，响应中不含任何材料或班级私有数据

#### Scenario: 外壳加载后无令牌取不到数据

- **WHEN** 外壳页面在无有效令牌的情况下请求任意业务数据接口
- **THEN** 系统返回 401 JSON 而非业务数据，页面展示登录引导而非任何私有内容

#### Scenario: 会话过期后前端回到登录页

- **WHEN** 用户持有的令牌在使用过程中过期，前端再次调用数据接口收到 401
- **THEN** 前端清除本地令牌并跳转登录页，登录获得新令牌后可继续操作

### Requirement: JWT 的签发内容、签名与有效期

访问令牌 MUST 是由服务端使用仅保存在服务端环境变量中的密钥、以服务端固定的签名算法（HS256 或更强）签名的 JWT；令牌声明 MUST 至少包含用户标识（sub）、签发时间（iat）与过期时间（exp），有效期 MUST 由服务端配置限定（默认 8 小时）。角色与班级 MUST NOT 取自客户端在请求中自报的字段。伪造签名、签名算法异常、过期、声明缺失或格式错误的令牌 MUST 一律视为无效。签名密钥 MUST NOT 出现在页面、接口响应、前端脚本或代码仓库中；生产模式缺少密钥时应用 MUST 拒绝启动。

#### Scenario: 登录获得结构正确的令牌

- **WHEN** 用户用正确凭据登录
- **THEN** 获得的令牌可被服务端用环境变量中的密钥验签，包含 sub、iat、exp，且 exp 与 iat 之差等于服务端配置的有效期

#### Scenario: 令牌内容被篡改即失效

- **WHEN** 请求携带修改过载荷或签名、或试图指定非预期签名算法的令牌
- **THEN** 服务端验签失败并返回 401，篡改后的角色、班级或用户标识均不生效

#### Scenario: 非标准位置的令牌不被接受

- **WHEN** 请求把令牌放在 URL 查询参数或非 Bearer 格式的头中调用受保护接口
- **THEN** 系统不接受该令牌并返回 401，避免令牌经日志或历史记录泄露

#### Scenario: 签名密钥不离开服务端

- **WHEN** 检查页面源码、接口响应、前端脚本或代码仓库中的配置
- **THEN** 均无法获得 JWT 签名密钥；仓库中只允许存在 `.env.example` 之类的占位说明，真实密钥只来自服务端环境变量

## REMOVED Requirements

### Requirement: 受保护页面的未认证访问重定向

**Reason**: 架构改为纯 Bearer JSON API 加公开静态前端外壳，不再存在"登录后才返回的服务端渲染页面"，到登录页的 302 重定向语义随之失效。

**Migration**: 由新增需求"公开页面外壳与受保护数据接口隔离"与修改后的"受保护接口的未认证访问拒绝"取代——未认证取数由服务端返回 401，前端收到 401 后跳转登录页。

### Requirement: 会话安全与密钥管理

**Reason**: 系统不再使用服务端签名会话与会话 Cookie，该需求的约束对象已不存在。

**Migration**: 由新增需求"JWT 的签发内容、签名与有效期"取代，密钥只来自环境变量、生产缺失即拒绝启动等约束保持不变。
