## Purpose

把本班 txt/md 教学材料转化为按班级强制隔离的 AI 知识库：材料上传后自动分块并调用服务端配置的嵌入 API 向量化，本班师生可用自然语言在两种模式下使用——知识检索返回可溯源的命中片段，知识问答在检索到相关知识时调用问答 API 生成带来源的回答、未检索到时由用户决定是否继续；索引持久化保存并可幂等重建。

## ADDED Requirements

### Requirement: 文本材料自动入库为知识片段

系统 MUST 在 txt/md 材料上传成功后，自动提取其文本内容、切分为带顺序编号与原文位置信息的片段，调用配置的嵌入 API 计算嵌入并写入该班知识库；仅扩展名为 txt 与 md 的材料进入知识库，其他允许类型的材料 MUST NOT 产生任何知识库片段。每个片段 MUST 携带其所属班级标识与来源材料标识，且班级标识 MUST 只取自访问令牌对应的已认证用户，不接受请求体中自报的班级。

#### Scenario: 上传文本材料后无需额外操作即可被检索

- **WHEN** 教师成功上传一个包含可识别文本内容的 txt 或 md 材料后，本班用户立即检索其中的内容
- **THEN** 系统返回来源于该材料的命中片段，无需人工执行索引命令

#### Scenario: 非文本材料不进入知识库

- **WHEN** 教师上传 pdf、docx、图片等非 txt/md 类型的允许材料
- **THEN** 系统不为其创建任何知识库片段，该材料内容不出现在任何检索或问答结果中

#### Scenario: 片段强制归属令牌用户所在班级

- **WHEN** 教师上传文本材料，且请求体中附带伪造的班级字段
- **THEN** 产生的全部片段的班级标识与该教师所属班级一致

#### Scenario: 入库失败不破坏材料上传结果

- **WHEN** 材料已保存且元数据已入库，但片段切分、嵌入 API 调用或写索引过程失败
- **THEN** 材料上传结果仍然成立（文件与材料记录保留），系统记录失败日志、不产生只写入一半的片段集合，并使该材料可被重建命令重新索引

### Requirement: 知识检索强制限定本班范围

系统 MUST 为已认证的教师与学生提供知识库语义检索；检索执行 MUST 以令牌用户所属班级作为强制过滤条件，任何查询参数或请求体中的班级标识都 MUST NOT 能扩大检索范围。系统 MUST 对空查询、纯空白查询与超长查询返回 400 级明确错误而不执行检索；未携带有效令牌的请求 MUST 返回 401。

#### Scenario: 本班用户检索命中本班材料

- **WHEN** 已认证用户用自然语言检索与其本班某份文本材料语义相符的内容
- **THEN** 系统返回按相关度排序的命中片段，且全部片段属于该用户所在班级

#### Scenario: 跨班内容在任何情况下都不泄露

- **WHEN** B 班材料中存在与查询完全相同或高度相符的内容，A 班用户执行同一查询
- **THEN** 返回结果中不包含任何 B 班片段、文件名或原文文本，如同 B 班数据不存在

#### Scenario: 学生与教师检索权限一致且仅及本班

- **WHEN** 同班的学生与教师分别执行相同检索
- **THEN** 两者都能检索本班知识库且可见范围相同，学生不因其角色被排除

#### Scenario: 未认证检索被拒绝

- **WHEN** 请求未携带访问令牌，或令牌过期、无效
- **THEN** 系统返回 401 JSON，不返回任何片段内容

#### Scenario: 非法查询输入被拒绝

- **WHEN** 提交空查询、纯空白查询或超过系统规定长度上限的查询
- **THEN** 系统不执行检索并返回 400 与明确的输入错误信息

### Requirement: 检索结果可溯源到来源材料

每条检索结果 MUST 展示来源材料的原始文件名、命中片段的文本内容以及该片段在原文中的位置或所属小节提示，并 MUST 提供指向该材料预览页对应位置的链接；溯源链接 MUST 经过相同的班级鉴权，跨班访问仍为 404。

#### Scenario: 结果包含来源与片段内容

- **WHEN** 检索产生命中结果
- **THEN** 每条结果至少展示来源文件名、命中片段文本与相关度信息，用户可判断答案出处

#### Scenario: 溯源链接可回到原文对应位置

- **WHEN** 用户点击某条结果的来源链接
- **THEN** 浏览器打开该材料预览页，并能定位到该片段在原文中的大致位置（行号或小节锚点）

#### Scenario: 结果按相关度排序且数量受限

- **WHEN** 检索存在多个命中
- **THEN** 结果按与查询的相关度从高到低排列，且一次返回数量不超过系统规定的上限

### Requirement: 知识问答基于检索到的知识生成带来源的回答

系统 MUST 为已认证的教师与学生提供知识问答：收到问题后先执行与知识检索相同的本班向量检索；当存在相关度达到系统规定阈值的命中时，系统 MUST 将命中片段作为依据组织提问，调用配置的问答 API 生成回答，并在响应中同时返回回答文本与作为依据的来源列表。系统 MUST 要求问答仅依据所提供的片段作答；片段不足以回答问题时，回答 MUST 明确说明材料中未找到答案，而不是编造材料以外的信息。

#### Scenario: 检索到相关知识时生成带来源的回答

- **WHEN** 用户以知识问答模式提问，且本班材料中存在相关度达标的片段
- **THEN** 系统调用问答 API 返回总结性回答，响应中同时给出支撑该回答的来源材料与片段信息

#### Scenario: 回答不超出本班材料依据

- **WHEN** 检索到的片段与问题主题相关但不足以回答该问题
- **THEN** 回答明确表示现有材料不足以回答，不把材料中没有的信息当作材料内容陈述

#### Scenario: 问答范围同样强制限定本班

- **WHEN** A 班用户提问，而答案仅存在于 B 班材料中
- **THEN** 系统视 A 班未检索到相关知识，问答过程不读取、不引用 B 班任何内容

#### Scenario: 学生与教师问答权限一致

- **WHEN** 同班学生与教师分别提出相同问题
- **THEN** 两者获得相同范围的检索依据与问答能力，学生不因其角色被排除

#### Scenario: 问答 API 调用失败时明确报错

- **WHEN** 问答 API 超时、返回错误或返回内容不可用
- **THEN** 系统返回 502 级明确错误，不返回残缺或张冠李戴的回答

### Requirement: 未检索到知识时由用户决定是否继续回答

当知识问答未检索到相关度达标的片段时，系统 MUST NOT 自行调用问答 API，而是返回"未检索到相关知识"的状态（不包含回答文本），并由用户选择是否仍要 AI 回答。用户明确确认后，系统 MUST 在不引用本班材料的情况下再次调用问答 API，并在响应中以显式标记表明该回答未基于本班材料；用户未确认时系统 MUST NOT 发起问答调用。前端界面 MUST 为该状态提供"继续回答/取消"的选择，且默认不继续。

#### Scenario: 无相关知识时先返回门控状态

- **WHEN** 用户提问后，本班知识库没有命中，或全部命中的相关度均低于规定阈值
- **THEN** 系统返回未检索到状态、回答内容为空，且本次请求不调用问答 API

#### Scenario: 用户确认继续后获得未基于材料的回答

- **WHEN** 用户在未检索到状态下明确选择继续回答
- **THEN** 系统调用问答 API 作答，响应显式标记该回答未基于本班知识库材料

#### Scenario: 用户取消则不产生回答

- **WHEN** 用户在未检索到状态下选择取消或关闭
- **THEN** 系统不被再次调用，界面不展示任何 AI 回答

### Requirement: 嵌入与问答调用通过服务端配置的 API 网关完成

系统 MUST 只在服务端调用嵌入与问答 API：API 地址、密钥与模型名 MUST 来自服务端环境变量；面向浏览器的前端 MUST 只与同源应用接口通信，MUST NOT 直接调用外部网关，MUST NOT 能接触到 API 密钥。缺少必要 API 配置时，知识库相关接口 MUST 返回明确的配置错误，而不是以其他方式静默失败。

#### Scenario: 浏览器不直接访问网关

- **WHEN** 用户使用检索、问答或材料入库相关功能
- **THEN** 浏览器仅向同源 `/api` 发起请求，嵌入与问答的外部调用全部由服务端发起

#### Scenario: 缺少 API 配置时给出明确错误

- **WHEN** 服务端未配置嵌入/问答所需的地址或密钥，用户调用入库、检索或问答接口
- **THEN** 系统返回明确的配置错误响应（如 503），错误信息不包含密钥内容

#### Scenario: 密钥不出现在响应与日志中

- **WHEN** 检查接口响应体、错误信息或应用日志
- **THEN** 其中不包含完整 API 密钥

### Requirement: 向量索引持久化与幂等重建

知识片段、嵌入向量与索引 MUST 持久化在服务端受管存储中并随应用数据卷保留，容器或进程重启后已入库材料 MUST 仍可被检索。系统 MUST 提供可重复执行的知识库重建命令：对文本材料（全部或尚未成功索引的范围）重新切分、嵌入并写入索引；同一材料重复重建 MUST NOT 产生重复片段。

#### Scenario: 容器重建后索引仍可用

- **WHEN** 文本材料上传入库后停止并删除应用容器，再重新启动
- **THEN** 无需重新上传即可检索到该材料的片段内容

#### Scenario: 重建命令幂等

- **WHEN** 对同一批材料连续执行两次知识库重建命令
- **THEN** 第二次执行后每个材料的片段数量与内容和第一次一致，不产生重复片段或重复命中

#### Scenario: 历史缺失索引可被回填

- **WHEN** 数据库中存在上传于旧版本、或此前索引失败的 txt/md 材料而知识库中缺少其片段
- **THEN** 执行重建命令后这些材料被完整索引并可被本班检索命中
