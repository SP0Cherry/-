## Why

目前材料只能下载后查看，教师无法在课堂上直接展示讲义；txt/md 文本材料中的知识无法被检索，学生只能凭文件名逐个下载查找；即便有检索结果，用户仍需自行阅读片段、归纳答案。本次变更新增文本材料在线预览，基于 txt/md 材料构建按班级隔离的语义知识库，并在知识库之上提供两种使用模式——**知识检索**（向量检索并给出答案出处）与**知识问答**（检索到相关知识时调用 API 生成带来源的总结回答；未检索到时由用户决定是否继续）。

## What Changes

- 教师上传表单新增 **txt、md** 两种允许格式；上传界面展示的完整允许格式清单及"支持在线预览"标注由服务端接口下发派生，不写死在前端。
- 新增**材料在线预览**：本班教师与学生均可在浏览器内预览 txt（纯文本等宽展示）与 md（在浏览器中安全渲染为排版结构）；预览通过受班级边界保护的内容接口取数（跨班 404），材料中的脚本内容不执行。
- 新增**班级知识库**：txt/md 材料上传成功后自动分块，并调用**服务端配置的嵌入 API**（OpenAI 兼容接口，默认模型 `course-embedding`，2048 维）计算嵌入，写入带班级标识的 sqlite-vec 向量索引；索引与材料同生命周期持久化；提供幂等的 `flask reindex-kb` 重建命令用于回填与失败修复。
- 新增知识库页面，提供两种模式（教师与学生均可使用）：
  - **知识检索**：自然语言提问 → 向量分析检索本班材料 → 按相关度返回命中片段，附来源材料名、小节/行号与可跳转到原文位置的溯源链接；任何情况下不泄露其他班级内容。
  - **知识问答**：先执行同一套知识检索；若检索到相关度达标的知识，携带检索片段调用问答 API（默认模型 `course-chat`）生成总结性回答，并一并展示答案出处；若未检索到相关知识，系统不直接生成答案，而是返回"未检索到相关知识"状态并请用户选择——用户确认继续后，AI 可在不引用本班材料的情况下作答，且回答被明确标注为"未基于本班材料"；用户也可取消。
- **嵌入/问答 API 配置**：通过 `EMBEDDING_BASE_URL`、`EMBEDDING_API_KEY`、`EMBEDDING_MODEL`、`EMBEDDING_DIM` 配置嵌入服务；问答复用同一 Base URL 与 API Key（网关限定问答模型为 `course-chat`，以 `LLM_MODEL` 配置）。密钥仅存在于服务端，浏览器只调用同源 `/api` 接口、不直接访问网关。
- 种子数据新增中英文文本示例材料（A/B 班内容不同），配置 API Key 后自动完成索引，`docker compose up` 即可演示检索、问答与跨班隔离。

> 本修订取代该变更早先版本中的两个决策：①嵌入由"随镜像分发的本地离线模型（FastEmbed/BGE，512 维）"改为上述**远程嵌入 API（2048 维）**；②预览与检索页面由"Jinja 服务端渲染"改为适配现已落地的 **JWT JSON API + 静态 vanilla JS 外壳**架构。

## Capabilities

### New Capabilities

- `knowledge-base`: 基于 txt/md 教学材料、按班级隔离的 AI 知识库——自动分块与 API 嵌入、班级强制范围的向量检索、命中结果内容溯源、检索基础上的 API 问答（含"未检索到由用户决定是否继续"的门控）、索引持久化与幂等重建。

### Modified Capabilities

- `teaching-materials`: 允许格式清单扩展 txt/md；上传界面清单由服务端接口下发；新增 txt/md 材料的班级内在线预览（安全渲染）要求。
- `app-foundations`: 预置演示数据扩展为包含可供知识库检索/问答演示的文本材料（A/B 班内容不同，可演示跨班隔离）。

## Impact

- **新增依赖**：`sqlite-vec`（SQLite 向量扩展）、`requests`（调用嵌入/问答网关）；不再需要早先规划的 `Markdown`、`bleach`、`fastembed`（md 改由前端安全渲染，嵌入改走 API）。
- **网络**：运行期需能通过 HTTPS 访问配置的嵌入/问答网关；材料文本与用户问题会发送至该网关（取舍：换来无需随镜像分发数百 MB 模型与 2048 维高质量嵌入）。部署时需保证容器出站访问与 API Key 有效。
- **代码**：新增 `app/kb/` 包（分块、嵌入客户端、问答客户端、向量存储、索引、检索/问答编排、Blueprint）；`materials` 模块新增内容接口，上传处理对 txt/md 增加 UTF-8 校验并在提交后触发索引；`models.py` 增加 `Material.indexed_at` 与知识片段表；`config.py`/`.env.example` 新增嵌入/问答/知识库配置（真实密钥不入库、不入镜像）；`cli.py` 新增 `reindex-kb`；`seed.py` 增加文本示例材料。
- **前端**：新增静态页 `kb.html`（检索/问答两种模式）与 `preview.html`（材料预览）及对应 vanilla JS；材料列表页增加预览入口与页面导航；零构建、无第三方脚本，CSP 维持现状。
- **接口**：新增 `GET /api/config`、`GET /api/materials/<id>/content`、`GET /api/kb/search`、`POST /api/kb/ask`，及公开外壳路由 `/kb`、`/materials/<id>/preview`；不改动现有鉴权与既有接口 HTTP 语义。
- **测试**：嵌入与问答提供 stub 后端（确定性、无网络），新增预览安全、知识库隔离/溯源、问答门控与网关错误映射测试，既有测试保持通过。
- **在途依赖**：本变更依赖 `jwt-bearer-auth` 的架构基线（其代码已落地、变更尚未归档），须在其基础上实施与归档。
