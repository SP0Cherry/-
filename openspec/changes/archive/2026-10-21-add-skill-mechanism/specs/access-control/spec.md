## ADDED Requirements

### Requirement: 技能管理的教师专属授权

系统 MUST 在服务端对技能上传、删除等管理操作执行角色校验：仅教师可以执行；学生即使绕过界面、直接提交完全合法的技能文件或调用管理接口，MUST 被拒绝（403），且 MUST NOT 创建、修改或删除任何技能记录。

学生 MUST 可以读取本班已启用技能并在提问时选择使用，但该读取与选择 MUST NOT 获得任何管理权限。授权判定 MUST 只依据服务端会话对应用户的真实角色，MUST NOT 信任请求中自报的角色字段。

#### Scenario: 学生直接上传技能被拒绝
- **WHEN** 已登录学生绕过前端，直接向技能上传接口提交合法技能文件
- **THEN** 系统返回 403，不写入技能记录

#### Scenario: 学生伪造教师角色无效
- **WHEN** 学生在上传请求或表单中附加 role=teacher 等自报字段
- **THEN** 系统仍按会话中的真实角色判定并返回 403

#### Scenario: 学生可读取已启用技能
- **WHEN** 已登录学生请求本班可选技能列表
- **THEN** 系统允许读取启用技能，但不返回任何管理操作能力

### Requirement: 技能与 MCP 工具引用的班级强制边界

系统 MUST 以登录用户所属班级作为技能、技能选择与 MCP 工具引用的服务端强制边界。任何来自请求参数、表单或查询串的班级标识 MUST NOT 扩大该边界。

跨班读取、删除或选择技能 MUST 返回 404，且 MUST NOT 泄露该技能是否存在。保存技能时解析 MCP 服务器名称、运行时执行工具引用时，MUST 只在本班范围内查找；其他班级同名服务器 MUST NOT 被用于通过校验或被调用。

#### Scenario: 跨班删除技能返回 404
- **WHEN** A 班教师尝试删除 B 班技能标识
- **THEN** 系统返回 404，B 班技能保持不变

#### Scenario: 跨班选择技能被拒绝
- **WHEN** A 班学生提问时携带 B 班技能标识
- **THEN** 系统返回 404，不应用该技能

#### Scenario: MCP 引用只解析本班服务器
- **WHEN** A 班与 B 班各有一个同名 MCP 服务器，A 班技能引用该名称
- **THEN** 系统只使用 A 班服务器进行保存校验与运行时调用，绝不使用 B 班服务器

#### Scenario: 伪造班级字段不能扩大边界
- **WHEN** 用户在技能列表、保存或提问请求中附带其他班级标识
- **THEN** 系统忽略该字段，仍只操作和返回会话所属班级的数据
