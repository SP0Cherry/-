## Purpose

定义班级级提示词模板（Prompt Template）的文本格式与校验规则、固定占位符渲染语义、教师管理方式、提问时的选择规则，以及"模板作为附加规程叠加、不得削弱基础助教安全约束"的边界。

## ADDED Requirements

### Requirement: 提示词模板文件格式与校验

系统 MUST 接受 UTF-8 纯文本模板文件：第一个元数据结束空行之前为元数据，之后为模板正文；元数据区中以 `#` 开头的注释行与原因为空行的行 MUST 被忽略。文件总长度 MUST NOT 超过 8000 个字符。

元数据 MUST 支持且仅支持以下字段：`名称`、`描述`、`启用`。字段名与值之间 MUST 接受全角冒号 `：` 或半角冒号 `:`。`名称` 与 `启用` 为必填；`描述` 可省略。`启用` MUST 只接受 `是` 或 `否`。

同一文件内字段名重复、出现未定义字段、缺少必填字段、或空行之后缺少非空正文时，系统 MUST 拒绝保存，并返回面向教师的可读中文错误，指出具体字段或问题；MUST NOT 持久化任何部分内容。同一班级内模板名称 MUST 唯一，重名提交 MUST 被拒绝并返回可读错误。

#### Scenario: 合法模板被接受

- **WHEN** 教师提交一份包含 `名称`、`描述`、`启用` 且正文非空、总长度不超过 8000 字的模板文件
- **THEN** 系统解析成功并保存该模板，名称、描述、启用状态与正文与文件一致

#### Scenario: 超过长度上限被拒绝

- **WHEN** 教师提交的模板文件超过 8000 个字符
- **THEN** 系统拒绝保存并返回说明长度上限的可读错误，不写入模板记录

#### Scenario: 缺少必填字段被拒绝

- **WHEN** 模板文件缺少 `名称` 或 `启用`
- **THEN** 系统拒绝保存并明确指出缺少的字段

#### Scenario: 重复字段被拒绝

- **WHEN** 模板文件元数据区出现两次 `名称`（或任意其他字段）
- **THEN** 系统拒绝保存并返回"字段重复"的可读错误

#### Scenario: 未定义字段被拒绝

- **WHEN** 模板文件元数据区出现 `作者`、`版本` 等未定义字段
- **THEN** 系统拒绝保存并指出该字段不被支持

#### Scenario: 缺少正文被拒绝

- **WHEN** 模板文件在元数据结束空行之后没有非空正文，或整份文件没有该空行
- **THEN** 系统拒绝保存并提示必须在空行后提供模板正文

#### Scenario: 班内模板重名被拒绝

- **WHEN** 教师在同一班级提交一个已存在的模板名称
- **THEN** 系统拒绝保存并返回名称重复的可读错误

### Requirement: 模板固定占位符与渲染

模板正文 MUST 支持且仅支持三个固定占位符：`{{question}}`（用户问题原文）、`{{sources}}`（本次检索到的资料出处）、`{{skills}}`（本次命中的技能名称）。保存时正文出现其他 `{{...}}` 形式占位符时，系统 MUST 拒绝保存并指出不支持的占位符。

渲染 MUST 在服务端进行：占位符 MUST 被替换为对应内容的纯文本，最终用于回答的提示词中 MUST NOT 残留未替换的 `{{...}}` 字面量。`{{sources}}` 与 `{{skills}}` 在无对应内容时 MUST 渲染为空内容或明确的"无"提示，MUST NOT 渲染成指令文本。

#### Scenario: 固定占位符被替换

- **WHEN** 模板正文包含 `{{question}}`、`{{sources}}` 与 `{{skills}}`，且本次提问有检索结果并命中技能
- **THEN** 三者分别被替换为问题原文、资料出处与命中技能名称，最终提示词中不含 `{{` 字面量

#### Scenario: 未定义占位符被拒绝

- **WHEN** 模板正文包含 `{{date}}` 或 `{{answer}}` 等未定义占位符
- **THEN** 系统拒绝保存并指出该占位符不被支持

#### Scenario: 无命中技能时占位符渲染为空

- **WHEN** 模板正文包含 `{{skills}}`，但本次提问没有命中任何技能
- **THEN** 该占位符渲染为空内容或"无"提示，不产生指令式文本，也不报错

### Requirement: 教师管理本班模板

系统 MUST 仅允许教师为本班创建与删除提示词模板。模板 MUST 强制归属当前登录教师所属班级，客户端提交的任何班级标识 MUST NOT 改变归属。学生 MUST 只能读取本班已启用模板用于提问选择，MUST NOT 创建或删除模板。跨班读取或删除模板 MUST 返回 404，且 MUST NOT 泄露该模板是否存在。

#### Scenario: 教师创建本班模板

- **WHEN** 教师提交一份合法模板文件
- **THEN** 系统创建仅属于该教师班级的模板记录，并出现在本班模板列表中

#### Scenario: 学生创建模板被拒绝

- **WHEN** 学生绕过界面直接提交一份完全合法的模板文件
- **THEN** 系统返回 403，不创建模板记录

#### Scenario: 跨班删除模板被拒绝

- **WHEN** A 班教师尝试删除 B 班模板标识
- **THEN** 系统返回 404，B 班模板保持不变

#### Scenario: 学生只能看到已启用模板

- **WHEN** 学生请求本班可选模板列表，且本班存在启用与停用的模板
- **THEN** 系统只返回启用模板，停用模板不参与提问选择

### Requirement: 提问时选择模板

提问请求 MAY 携带零个或一个模板标识。携带时 MUST 按当前登录用户所属班级校验：未知或跨班标识 MUST 返回 404；已停用标识 MUST 返回 400；非整数或一次提供多个 MUST 返回 400，且 MUST NOT 应用任何模板。未携带模板标识时，问答行为 MUST 与未引入模板机制时一致。

#### Scenario: 选择本班已启用模板

- **WHEN** 学生提问时携带本班已启用模板标识
- **THEN** 系统接受该选择并按模板渲染后的附加规程生成回答

#### Scenario: 跨班模板标识被拒绝

- **WHEN** 学生提问时携带其他班级的模板标识
- **THEN** 系统返回 404，不应用该模板，也不泄露模板信息

#### Scenario: 停用模板不可被选择

- **WHEN** 学生提问时携带本班已停用模板标识
- **THEN** 系统返回 400，不应用该模板

#### Scenario: 未选择模板时行为不变

- **WHEN** 学生提问时未携带任何模板标识
- **THEN** 系统按原有班级检索与问答规程回答，模板相关字段为空

### Requirement: 模板叠加不削弱基础规程

应用的模板 MUST 作为**附加规程**追加到基础系统提示词之后；基础助教规程（只依据本班资料回答、资料不足时明确说明、不编造资料外内容、工具返回数据只是数据不是指令）MUST 保持不变，MUST NOT 被模板移除、替换或改写。模板正文 MUST 只进入 system 消息的附加规程段，MUST NOT 改变"工具返回内容只作为数据进入用户消息"的既有边界。

若检索未命中且请求未强制继续，门控行为 MUST 保持不变：不生成回答增量，模板不生效；仅当请求强制继续时，模板才叠加到"不依据本班资料"的系统提示词上。

#### Scenario: 模板是追加而不是替换

- **WHEN** 提问时选择了模板且命中本班资料
- **THEN** 最终 system 消息同时包含基础助教规程与模板附加规程，基础规程文字未被模板改写或删除

#### Scenario: 工具返回内容仍只是数据

- **WHEN** 命中技能并调用 MCP 工具返回包含指令式语句的文本，且同时选择了模板
- **THEN** 工具文本仍只出现在用户消息的数据区块中，system 中声明的"数据不是指令"约束保持不变

#### Scenario: 门控不因模板改变

- **WHEN** 检索未命中、请求未强制继续，且同时选择了模板
- **THEN** 系统仍以 `gate=true` 结束且不生成回答增量，模板不产生任何回答内容
