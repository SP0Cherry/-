## Purpose

为班级 MCP 工具调用提供可追溯的审计能力：记录谁在何时调用了哪个 `工具@服务器`、结果状态与原因，并让教师只能查看本班的审计记录。

## ADDED Requirements

### Requirement: MCP 工具调用审计记录

系统 MUST 为每一次 MCP `tools/call` 尝试写入一条审计记录，覆盖两类来源：学生问答命中技能后服务端发起的调用，以及教师通过手动工具调用接口发起的调用。内置工具 `knowledge_search` MUST NOT 计入 MCP 审计。

每条记录 MUST 至少包含：`工具@服务器` 引用、工具名、服务器名、状态（`ok`、`denied` 或 `error`）、操作用户与时间（UTC）。非 `ok` 状态 MUST 保存可读原因。记录 MUST 归属于发起调用用户所在班级，MUST NOT 因请求参数改变归属。

状态判定 MUST 与调用结果一致：远端调用成功并返回可用结果记为 `ok`；因本班未登记服务器、服务器未连接、工具不在缓存或越权而拒绝调用记为 `denied`；远端超时、鉴权失败、JSON-RPC 错误或结果标记为错误记为 `error`。被 `denied` 的尝试 MUST NOT 发起远端请求，但仍 MUST 留下审计记录。

审计写入 MUST NOT 阻断问答或工具调用的主路径：写入失败时 MUST 被隔离并记录服务端日志，调用方仍返回原有业务结果。审计记录与任何审计响应 MUST NOT 包含 MCP 服务器令牌。

#### Scenario: 技能触发的成功调用被记录

- **WHEN** 学生提问命中带 MCP 工具的技能，且本班服务器已连接、工具在缓存中、远端调用成功
- **THEN** 新增一条状态为 `ok` 的审计记录，包含 `工具@服务器`、服务器名、工具名、学生用户名与调用时间

#### Scenario: 未连接导致的拒绝被记录

- **WHEN** 学生提问命中技能，但对应服务器已断开
- **THEN** 新增一条状态为 `denied` 的审计记录并保存原因，问答仍正常返回

#### Scenario: 远端失败被记录

- **WHEN** 远端工具调用超时、鉴权失败或返回 JSON-RPC 错误
- **THEN** 新增一条状态为 `error` 的审计记录并保存可读原因，问答仍正常返回

#### Scenario: 内置检索不计入 MCP 审计

- **WHEN** 技能只引用内置工具 `knowledge_search`
- **THEN** 不新增任何 MCP 审计记录

#### Scenario: 教师手动调用被记录

- **WHEN** 教师通过手动工具调用接口调用本班服务器工具并成功或失败
- **THEN** 新增对应状态的审计记录，操作用户为该教师

#### Scenario: 审计写入失败不影响调用

- **WHEN** 审计记录写入数据库失败
- **THEN** 工具调用与问答结果仍按原逻辑返回，系统记录服务端日志且不向客户端暴露内部错误

#### Scenario: 审计不含令牌

- **WHEN** 任意工具调用成功、被拒绝或失败
- **THEN** 生成的审计记录及后续审计查询响应中均不出现服务器令牌内容

### Requirement: 教师专属的班级审计查询

系统 MUST 提供查询本班 MCP 工具调用审计的接口，并 MUST 仅允许教师访问：已登录学生调用 MUST 返回 403；未认证请求 MUST 返回 401。

查询 MUST 以服务端会话中的班级为唯一边界，只返回本班用户产生的记录，MUST NOT 返回其他班级记录，MUST NOT 接受请求参数扩大范围。结果 MUST 按时间倒序排列，并 MUST 支持分页参数限制返回条数（默认 50，最大 200），以便在记录较多时稳定翻页。

每条返回项 MUST 至少包含：唯一标识、`工具@服务器` 引用、工具名、服务器名、状态、操作用户名、原因（可为空）与时间。结果 MUST 附带是否还有更多记录的可判断信息。空结果 MUST 返回空列表，而不是错误。响应 MUST NOT 包含令牌、技能正文或工具返回内容。

#### Scenario: 教师查看本班审计

- **WHEN** A 班教师请求审计列表，本班存在成功、拒绝与失败记录
- **THEN** 响应按时间倒序返回本班记录，每条包含工具引用、状态、用户名与时间

#### Scenario: 学生访问被拒绝

- **WHEN** 已登录学生请求审计列表
- **THEN** 系统返回 403，不返回任何审计数据

#### Scenario: 未认证访问被拒绝

- **WHEN** 未携带有效 Bearer 令牌请求审计列表
- **THEN** 系统返回 401

#### Scenario: 跨班记录不可见

- **WHEN** A 班与 B 班都有工具调用记录，A 班教师请求审计列表
- **THEN** 响应中只包含 A 班记录，不包含 B 班的任何标识或内容

#### Scenario: 分页返回

- **WHEN** 教师传入较小的条数限制并连续翻页
- **THEN** 每页返回不超过限制条数，记录不重复且整体保持时间倒序，并正确标识是否还有更多记录

#### Scenario: 空审计返回空列表

- **WHEN** 本班尚无任何 MCP 工具调用记录
- **THEN** 系统返回 200 与空列表，不返回错误
