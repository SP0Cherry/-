# qa-skills Specification

## Purpose

定义班级级技能（Skill）的 SKILL.md 文本格式、教师管理方式、学生提问时的选择与命中规则，以及技能引用 MCP 工具时的保存校验、服务端调用与“工具结果只作为数据”的安全约束。

## Requirements

### Requirement: SKILL.md 技能文件格式

系统 MUST 接受 UTF-8 纯文本技能文件：第一个元数据结束空行之前为元数据，之后为引导规程正文；元数据区中以 `#` 开头的注释行与原因为空行的行 MUST 被忽略。文件总长度 MUST NOT 超过 8000 个字符。

元数据 MUST 支持且仅支持以下字段：`名称`、`适用条件`、`资料`、`工具`、`启用`。字段名与值之间 MUST 接受全角冒号 `：` 或半角冒号 `:`。`名称`、`适用条件`、`启用` 为必填；`资料` 与 `工具` 可省略。`启用` MUST 只接受 `是` 或 `否`。

同一文件内字段名重复、出现未定义字段、缺少必填字段、或空行之后缺少非空正文时，系统 MUST 拒绝保存，并返回面向教师的可读中文错误，指出具体字段或问题；MUST NOT 持久化任何部分内容。`资料` 是技能的学科标签，仅用于展示与说明，MUST NOT 单独改变班级检索边界。

#### Scenario: 合法数学技能被接受

- **WHEN** 教师提交一份包含 `名称`、`适用条件`、`资料`、`工具`、`启用` 且正文非空的数学技能文件，总长度不超过 8000 字
- **THEN** 系统解析成功并保存该技能，名称、适用条件、资料、工具引用、启用状态与正文与文件一致

#### Scenario: 超过长度上限被拒绝

- **WHEN** 教师提交的技能文件超过 8000 个字符
- **THEN** 系统拒绝保存并返回说明长度上限的可读错误，不写入技能记录

#### Scenario: 缺少必填字段被拒绝

- **WHEN** 教师提交的技能文件缺少 `名称`、`适用条件` 或 `启用` 中任意一项
- **THEN** 系统拒绝保存并明确指出缺少的字段

#### Scenario: 重复字段被拒绝

- **WHEN** 同一技能文件的元数据区出现两次 `名称`（或任意其他字段）
- **THEN** 系统拒绝保存并返回“字段重复”的可读错误

#### Scenario: 未定义字段被拒绝

- **WHEN** 技能文件元数据区出现 `作者`、`版本` 等未定义字段
- **THEN** 系统拒绝保存并指出该字段不被支持

#### Scenario: 缺少正文被拒绝

- **WHEN** 技能文件在元数据结束空行之后没有非空正文，或整份文件没有该空行
- **THEN** 系统拒绝保存并提示必须在空行后提供引导规程正文

#### Scenario: 注释行被忽略

- **WHEN** 元数据区包含以 `#` 开头的注释行
- **THEN** 系统忽略这些行，不影响字段解析结果

### Requirement: 教师管理本班技能

系统 MUST 仅允许教师为本班上传与删除技能。技能 MUST 强制归属当前登录教师所属班级，客户端提交的任何班级标识 MUST NOT 改变归属。学生 MUST 只能读取本班已启用技能用于提问选择，MUST NOT 上传或删除技能。

同一班级内技能名称 MUST 唯一；重名提交 MUST 被拒绝并返回可读错误。跨班读取或删除技能 MUST 返回 404，且 MUST NOT 泄露该技能是否存在。删除技能 MUST 同时解除其工具引用，后续提问 MUST NOT 再执行该技能。

#### Scenario: 教师上传本班技能

- **WHEN** 教师提交一份合法技能文件
- **THEN** 系统创建仅属于该教师班级的技能记录，并出现在本班技能列表中

#### Scenario: 学生上传被拒绝

- **WHEN** 学生绕过界面直接提交一份完全合法的技能文件
- **THEN** 系统返回 403，不创建技能记录

#### Scenario: 教师删除跨班技能被拒绝

- **WHEN** A 班教师尝试删除 B 班技能标识
- **THEN** 系统返回 404，B 班技能保持不变

#### Scenario: 班内技能重名被拒绝

- **WHEN** 教师在同一班级提交一个已存在的技能名称
- **THEN** 系统拒绝保存并返回名称重复的可读错误

#### Scenario: 学生只能看到已启用技能

- **WHEN** 学生请求可选技能列表，且本班存在启用与停用的技能
- **THEN** 系统只返回启用技能，停用技能不参与提问选择

### Requirement: 工具字段与 MCP 引用格式

技能 `工具` 字段 MUST 支持以逗号、顿号或分号分隔的多个引用，并 MUST 支持两类引用：

- 内置工具 `knowledge_search`；
- MCP 工具引用 `工具名@服务器名`，其中工具名 MUST 符合小写字母开头、仅含小写字母/数字/下划线的规则，服务器名 MUST 与本班已登记服务器名称完全一致。

引用格式非法（缺少 `@`、包含多个 `@`、工具名不合法或服务器名为空）时，系统 MUST 拒绝保存技能并返回可读错误。`工具` 为空或省略 MUST 表示该技能不调用任何工具。

#### Scenario: 合法工具引用被解析

- **WHEN** 技能 `工具` 为 `knowledge_search, formula_hint@campus-tools`
- **THEN** 系统解析为一个内置引用与一个 MCP 引用，并分别保存

#### Scenario: 非法 MCP 引用被拒绝

- **WHEN** 技能 `工具` 出现 `formula-hint@campus-tools`、`formula_hint@@campus-tools` 或 `formula_hint@`
- **THEN** 系统拒绝保存并指出工具引用格式错误

### Requirement: 保存时校验 MCP 工具绑定

保存带 MCP 引用的技能时，系统 MUST 在本班范围内解析服务器名称，并 MUST 同时满足：服务器存在、服务器当前已连接、且引用的工具名存在于该服务器最近一次 `tools/list` 缓存中。任一条件不满足时，系统 MUST 拒绝保存整份技能，并返回面向教师的可读错误，说明是服务器未登记、未连接还是工具未在缓存中。

校验 MUST 以当前登录教师所属班级为边界：其他班级同名服务器 MUST NOT 被用于通过校验。服务端 MUST NOT 在校验错误信息或技能记录中回显任何 Bearer 令牌。

#### Scenario: 已连接且工具已缓存时保存成功

- **WHEN** 教师保存技能，引用本班已连接服务器中缓存存在的工具
- **THEN** 系统保存技能及其工具引用

#### Scenario: 服务器未连接时拒绝保存

- **WHEN** 技能引用本班已登记但当前未连接的服务器
- **THEN** 系统拒绝保存并提示服务器未连接，技能记录不写入

#### Scenario: 工具不在缓存中时拒绝保存

- **WHEN** 技能引用本班已连接服务器，但工具名不在其缓存清单中
- **THEN** 系统拒绝保存并提示该工具尚未通过工具发现缓存

#### Scenario: 仅能绑定本班服务器

- **WHEN** 技能引用的服务器名称只存在于其他班级
- **THEN** 系统拒绝保存并提示本班不存在该服务器

#### Scenario: 回应不含令牌

- **WHEN** 保存技能成功或失败
- **THEN** 任何响应体、错误信息与技能列表均不包含服务器 Bearer 令牌内容

### Requirement: 提问时选择技能与命中判定

学生提问时 MUST 可以选择零个或多个本班已启用技能。请求中携带的技能标识 MUST 按当前登录用户班级校验：未知或跨班标识 MUST 返回 404；已停用标识 MUST 返回 400；学生 MUST NOT 能通过请求参数启用停用技能。

未选择任何技能时，问答行为 MUST 与未引入技能机制时一致。选择技能后，系统 MUST 用问题文本与技能的 `适用条件` 做关键词命中判定：适用条件按逗号/顿号/分号拆分为关键词，问题包含任一关键词（英文不区分大小写）即视为命中。未命中的已选技能 MUST NOT 改变回答规程，并在流式 `meta` 中标记为未命中。

多个技能同时命中时，系统 MUST 按技能标识顺序稳定应用，MUST NOT 因请求顺序之外的因素改变结果。

#### Scenario: 命中数学技能

- **WHEN** 学生选择数学技能并提问“去括号时总是漏乘”，适用条件包含“去括号”
- **THEN** 系统将该技能正文作为回答规程应用，并在 `meta` 中标记该技能命中

#### Scenario: 已选但未命中

- **WHEN** 学生选择数学技能，但问题不包含其任何适用条件关键词
- **THEN** 系统不应用该技能规程，并在 `meta` 中标记未命中

#### Scenario: 未选择技能时行为不变

- **WHEN** 学生提问时未携带任何技能标识
- **THEN** 系统按原有班级检索与问答规程回答，`meta` 中技能列表为空

#### Scenario: 停用技能不可被选择

- **WHEN** 学生请求携带本班已停用技能标识
- **THEN** 系统返回 400，不应用该技能

#### Scenario: 跨班技能标识被拒绝

- **WHEN** 学生请求携带其他班级的技能标识
- **THEN** 系统返回 404，不泄露该技能信息

### Requirement: 命中技能的 MCP 工具执行

对每个命中技能，系统 MUST 执行其工具引用。内置 `knowledge_search` MUST 使用当前用户的班级边界执行知识检索，并把检索结果计入回答依据。MCP 引用 MUST 在服务端重新校验：服务器仍属于本班、仍处于已连接状态、工具仍在缓存清单中；随后使用服务端保存的令牌调用远端 `tools/call`。

运行时不满足班级归属或连接条件时，系统 MUST 将该次调用记为 `denied`，MUST NOT 发起远端调用；远端调用失败或返回 JSON-RPC 错误时 MUST 记为 `error`。任何非 `ok` 状态 MUST 在流式响应的 `tool_calls` 中可见，MUST NOT 被静默忽略，且 MUST NOT 导致整条问答主路径被阻断。

远端工具返回的文本 MUST 作为**数据**追加到用户消息中，并以明确的数据区块标识；MUST NOT 被写入 system 消息，MUST NOT 被当作系统指令或改变回答规程。即使工具输出包含“忽略以上指令”等指令式文本，系统也 MUST 只将其视为数据。

#### Scenario: 成功调用 MCP 工具

- **WHEN** 命中技能引用本班已连接且缓存存在的工具，远端返回文本结果
- **THEN** 系统记录该调用状态为 `ok`，并把结果以数据区块追加到用户消息后生成回答

#### Scenario: 调用前已断开记为 denied

- **WHEN** 技能保存后服务器被断开，学生提问命中该技能
- **THEN** 系统不发起远端调用，`tool_calls` 中该引用状态为 `denied`，问答继续

#### Scenario: 越权服务器记为 denied

- **WHEN** 运行时无法在本班解析到技能引用的服务器
- **THEN** 系统不发起远端调用，`tool_calls` 中该引用状态为 `denied`

#### Scenario: 远端失败记为 error

- **WHEN** 远端工具调用超时、返回 401 或 JSON-RPC 错误
- **THEN** 系统在 `tool_calls` 中记录 `error` 状态，问答流程继续并返回可见状态

#### Scenario: 工具输出只是数据

- **WHEN** MCP 工具返回包含指令式语句的文本
- **THEN** 该文本只出现在 user 消息的数据区块中，system 规程保持不变，回答按原技能规程生成
